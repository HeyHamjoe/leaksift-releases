# LeakSift

LeakSift is a free, local-first sensitive data scanner. It runs on your own machine and finds secrets and personal data in your files without uploading anything.

**Website:** https://leaksift.com

## Download

Get the latest installers from the [Releases page](https://github.com/HeyHamjoe/leaksift-releases/releases/latest):

- macOS: `LeakSift-mac.dmg`
- Windows: `LeakSift-Setup.exe`
- Checksums: `SHA256SUMS.txt`

## Preview build

Current builds are preview releases and are unsigned.

- **macOS:** right-click the app and choose **Open**.
- **Windows:** in SmartScreen, click **More info**, then **Run anyway**.
